## Controlled workflow
SEARCH → EXACT-SOURCE CAPTURE → HASH → DUPLICATE TEST → PROMPT/NOT-PROMPT CLASSIFICATION → CANONICAL/DISCOVERY DECISION → PROVENANCE → SEMANTIC VALIDATION → RUNTIME TEST → RELEASE.

## Operator modes
USE_SOURCE = execute source text unchanged.
AUDIT_SOURCE = inspect without rewriting.
DERIVE_OPTIMIZED = create derived variant linked to source.
TEST_PROMPT = execute test and record result.

## Anti-regression
Never overwrite SOURCE_CANONICAL. Never silently normalize source wording. Never merge independent prompts merely because topics are similar. Never promote a response/report/lesson plan as a prompt without evidence. Never equate Discovery with Validation or Runtime Success.
