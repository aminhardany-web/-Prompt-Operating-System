# Prompt Library

Central repository for all organized prompts, indexed by category, domain, and workflow.

## Subsections

- **00_Master_Index** - Master index and cross-reference system
- **01_Master_Prompts** - Core foundational prompts
- **02_Domain_Prompts** - Domain-specific prompt collections
- **03_Workflow_Prompts** - Workflow-based prompt sequences
- **04_AI_Roles** - Role-based prompt definitions
- **05_Tested_Prompts** - Validated and tested prompts
- **06_Templates** - Prompt templates and frameworks
