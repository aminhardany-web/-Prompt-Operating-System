## 1. Purpose

Controlled system for exact-source prompt extraction, provenance, deduplication, lifecycle, lineage, dependencies, change control, persistence, testing and validation.

## 2. Non-negotiable rules

1. Source text is never silently rewritten, summarized or optimized.
2. Source, Extraction, Evidence, Canonical, Runtime and Validation are separate states.
3. No completion/verification claim without evidence.
4. No dependency or project relation is inferred when not explicitly evidenced.
5. Historical versions remain preserved and are never silently merged into the active baseline.
6. A frozen source text is not automatically a tested or production-ready prompt.
7. Chat archive is source evidence; Prompt Bank is exact-source corpus; Prompt-OS Master Index is control registry; Memory is continuity/metadata, not the full text store.
8. Every change requires Change ID, scope, authority, evidence, previous state, new state and validation status.
9. Release/Active Production requires passing runtime and semantic validation gates.
10. Global 100% historical recall is not claimed until the unresolved candidate queue is semantically closed.
